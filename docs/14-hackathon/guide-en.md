# Hackathon — Prove Yourself

> 2 hours. Business → Database → Code. Prove you can do it.

The time has come. For the past 2 days, we walked you through every step. Now you walk on your own.

---

## Rules

1. **Form teams of 3–4** — mix experience levels
2. **Pick a feature from the menu below** — one feature per team
3. **Draw the ERD on paper FIRST** — the facilitator must check your ERD before you write any code
4. **Build the feature** — write real code
5. **Tests must pass** — the feature is not done until the test passes
6. **Demo** — 3 minutes per team

## Demo Rules

- **3 minutes per team** — no extensions
- Show the ERD you drew on paper
- Show the code you wrote
- Run the test live
- **The feature is not done until the test passes**
